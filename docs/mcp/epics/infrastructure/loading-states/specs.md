# Loading States Feature

## Overview

The Loading States feature provides appropriate loading indicators, skeleton screens, and progress indicators for better user experience during async operations.

## Feature Goals

- Show skeleton loaders for lists and tables
- Display loading indicators for async operations
- Provide progress indicators for long-running operations
- Improve perceived performance

## UI Requirements

### Loading Components

**Skeleton Components**:
- `RegistryCardSkeleton` - For registry list
- `ServerRowSkeleton` - For server table
- `DetailsSkeleton` - For detail pages

**Loading Indicators**:
- Spinner for async operations
- Progress bar for long operations
- Inline loading states for buttons
